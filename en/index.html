WTFML

Wonderful Tremendous Fantastic Minecraft Launcher

An elegant, beautiful, all-in-one, modern Minecraft launcher.

Download

A single exe — download and run, nothing to install. Available for Windows x64.

Scenic Themes

Three scenic themes, Alpine Dusk, Glacier Lake and Sunset Cliffs, over a frosted interface. Follows the system light or dark mode; the background image and accent color can be customized.

Learn more →

All-in-One Installation

Vanilla, Fabric, Quilt, Forge and NeoForge clients, plus Paper, Purpur and Spigot servers. Modpacks and MultiMC / Prism instances import directly.

Learn more →

Safe Upgrades

A new game version can be installed as a copy or in place. Every in-place upgrade is preceded by a verified full snapshot, so it can be rolled back.

Learn more →

Agent

Connects an OpenAI-compatible model to analyze logs and crash reports; every change requires the user’s approval.

Learn more →

Toolbox

Common tools for enchanting order, coordinate conversion, beacons, brewing, banners, colored text, server ping and more.
