WTFML 功能 GitHub EN

功能详解

外观

内置暮色雪山、冰川碧湖、落日海崖三套风景主题，界面通体磨砂，可跟随系统深浅色。

  • 自定义背景图、主题色与文字不透明度均可调整。
  • 主页问候问候语随时段变化，下方附一句每日一言。
  • 即时保存设置修改后即时保存，无需点击「应用」。

安装与下载

可安装原版、Fabric、Quilt、Forge、NeoForge 客户端，以及 Paper、Purpur、Spigot 服务端。

  • 下载支持并发、限速、代理与断点续传。
  • 文件复用已有文件先行校验，可用则不再重复下载。
  • 安全校验无法校验完整性的模组文件不会写入。

整合包

可导入 ZIP、mrpack、CurseForge 导出包与 MultiMC / Prism 实例。

  • 更多格式安装 7-Zip 后可导入 RAR 与 7z 整合包。
  • 导入检查导入前识别游戏版本与加载器，提示潜在冲突。
  • 安全导出导出的整合包不含账号信息。

实例与升级

实例可分组、收藏；模组、资源包、光影、数据包、存档与服务器列表集中管理。

  • 安全升级原地升级前先做完整快照并校验，出现问题可以回滚。
  • 备份支持世界备份与完整实例快照。
  • 删除保护删除的实例移入回收站，且需二次确认。

智能体

接入兼容 OpenAI 接口的模型，协助分析日志与崩溃报告。

  • 围绕实例对话锁定所选实例，可查看其目录与配置。
  • 逐次确认写入、删除等操作均需用户逐次批准。
  • 写前备份修改文件前先行备份，可以回退。

工具箱

收录附魔、坐标、信标、酿造、旗帜、彩色文本、服务器延迟等常用工具。

  • 附魔助手计算铁砧经验惩罚与最优合成顺序。
  • 坐标换算解析 F3+C 坐标，换算下界与主世界位置。
  • 旗帜设计预览图案，列出合成步骤、材料与指令。

全部功能

  • 一站式安装原版、Fabric、Quilt、Forge、NeoForge 客户端，以及 Paper、Purpur、Spigot 服务端。
  • 整合包导入 ZIP、mrpack、CurseForge 导出包与 MultiMC / Prism 实例；安装 7-Zip 后另支持 RAR、7z。
  • 实例分组、收藏；模组、资源包、光影、数据包、存档、服务器列表集中管理。
  • 安全升级更换游戏版本时可另存副本或原地升级；原地升级前先做完整快照并校验，可以回滚。
  • 下载并发、断点续传、限速、代理；已有文件先行校验，可用则不再重复下载。
  • Java识别本机已安装的 Java，缺少时从 Adoptium 下载。
  • 服务端控制台、server.properties 编辑、白名单 / OP / 封禁、备份。
  • 工具箱附魔顺序、坐标换算、信标、酿造、旗帜、彩色文本、服务器延迟等。
  • 智能体接入兼容 OpenAI 接口的模型，协助分析日志与崩溃报告；所有修改均需用户确认。
  • 外观三套风景主题，界面通体磨砂，背景图与主题色均可自定义。
